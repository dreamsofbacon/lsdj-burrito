Dreamy_bacon's LSDJ Burrito

LSDj on the M-VAVE FM-1, played from its keys and knobs.

Connect

Plug the FM-1 in with a USB data cable, with LSDJ Burrito running. Use Chrome or Edge and allow MIDI access when asked. Or, with a Bluetooth build and BLUETOOTH: DEVICE on in the FM-1's settings (GLO), connect without a cable. This page only talks to the running firmware: songs, settings, effects and colours. It never writes firmware.

Live effects

Follows the FM-1 as you play. Move a slider to change an effect on the FM-1 straight away; Keep on FM-1 stores the setup (as SAVE does).

Echo

Songs

Export the FM-1's songs as lsdj.sav, or replace them with a 128 KiB .sav. The FM-1 keeps its songs if an import fails.

Colours

Make a custom theme: start from a preset, change any colour, then send it. The FM-1 uses it as THEME: CUSTOM.

Settings

Is your LSDj ROM supported?

Choose your own lsdj.gb. It is only read here, in your browser: nothing is uploaded or sent anywhere.

Installing from this page is switched off for now

An earlier version of this page installed firmware and left an FM-1 unable to start. Until installing is proven safe it stays off: install LSDJ Burrito with M-UPGRADE. Everything above works with the firmware that is already running.
