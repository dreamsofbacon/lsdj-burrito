Connect

Plug the FM-1 in with a USB data cable, with LSDJ Burrito running. Use Chrome or Edge and allow MIDI access when asked. Or, with a Bluetooth build and BLUETOOTH: DEVICE on in the FM-1's settings (GLO), connect without a cable. Connecting reaches the running firmware: songs, settings, effects and colours. Installing firmware is its own section below.

Live effects

Follows the FM-1 as you play: a control the FM-1 changes lights up. Changes here go to the FM-1 straight away; Keep on FM-1 stores the setup (as SAVE does). The cards are the FM-1's effects pages; K1-K4 are the knobs that play them there.

Songs

Export the FM-1's songs as lsdj.sav, or replace them with a 128 KiB .sav. The FM-1 keeps its songs if an import fails.

Files with exactly 16 extra trailing bytes can be imported only after you confirm using the first 131072 bytes. The extra bytes' format is not verified; your original file is never changed.

Colours

Make a custom theme: start from a preset, change any colour, then send it. The FM-1 uses it as THEME: CUSTOM.

Settings

MIDI

Clock in, Transport and Sync delay: LSDj with SYNC = MIDI follows the clock. Note in: LSDj with SYNC = KEYBD plays the notes (like the FM-1's keys in note mode). Clock out: LSDj with SYNC = LSDJ leads; the FM-1 sends MIDI clock, Start and Stop. CC to effects: the first channel controls PU1, the next PU2, then WAV and NOI.

CC numbers for the effects

Prepare firmware from your LSDj ROM

Choose your own lsdj.gb. It is only read here, in your browser: nothing is uploaded or sent anywhere.

FM-1_972 includes the latest accent-colour FX bars, choice selectors, no channel tint, and CPU1 save fixes from alpha 71. Preparing firmware never installs it automatically.

Experimental FM-1_972 template: ordinary Game Boy controls and emulation; version-specific tempo shortcuts, MIDI clock integration, song cues and cursor-following effects are disabled. Sample banks keep their original numbers. Back up your songs before switching LSDj versions; save compatibility is not guaranteed.

Install firmware

USB flashing is a separate, explicit action. Back up songs first and keep stable power, this tab in front and the USB cable connected. A previous interrupted web install left a device unable to boot. Package validation and simulated recovery tests do not guarantee recovery on hardware. M-UPGRADE is an alternative for the downloaded package.

Virtual FM-1 Experimental


Runs the actual FM-1 firmware package locally using Joakim Eriksson's FM-1 emulator, with a 3D instrument view. No firmware uploads, MIDI connections or physical device writes.



















Choose a firmware file, or preview the package you prepared above. The emulator loads on demand.













Click instrument keys; drag knobs vertically or scroll over them. Focus the instrument for keyboard controls: arrows = directions, Z/X = B/A, Shift/Enter = Select/Start. These press FM-1 keys; their behavior depends on the firmware. Switching tabs pauses emulation.




A VS Code embedded-browser tab crashed during testing; a fresh tab passed longer checks. That issue is unresolved. Prefer regular Chrome or Edge for experimentation.


Session only: Stop, restart or reload discards virtual songs/settings, including changes saved inside the virtual device. The Songs and Settings sections above control the physical FM-1, not this emulator. Firmware simulation does not prove hardware safety or accurate audio timing. Emulating LSDj inside the FM-1 is demanding and may run below real-time.
