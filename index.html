Dreamy_bacon's LSDJ Burrito

LSDj on the M-VAVE FM-1, played from its keys and knobs.

Installing from this page is switched off

An earlier version of this installer left an FM-1 unable to start (it had to be recovered with a hardware tool). Until the cause is found and the install is proven safe, this page does not write anything to an FM-1: it has no install, restore or song import.
