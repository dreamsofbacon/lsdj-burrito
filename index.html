Connect your FM-1

Turn the FM-1 on with LSDJ Burrito running, plug it in with a USB data cable, then press Connect and allow MIDI access.

Bluetooth, and if it doesn't connect

Bluetooth needs a Bluetooth build with BLUETOOTH: DEVICE on in the FM-1's settings (GLO). Songs move slower over Bluetooth.

No FM-1 found? Use a data cable (some charge-only cables don't carry data), check the FM-1 is on and close other music apps that may hold its MIDI port. Installing firmware is done from Install, not here.

Effects

How the effects work

Changes go to the FM-1 straight away. Keep on FM-1 stores them, as the SAVE button does. K1-K4 are the knobs that play each control on the FM-1; turn SELECT there to change pages. A control the FM-1 changes lights up here.

By default this follows the FM-1: the channel under its cursor and the page it shows. Pick a channel or page to edit something else.

MASTER, ECHO and ECHO MOD are shared by all channels; the other pages are per channel. MASTER K1: All FX bypasses every effect without losing settings; FILTER K1: Channel FX bypasses one channel. Firmware before FM-1_975 shows its older layout.

Songs

Back up

Save all the FM-1's songs to this computer as lsdj.sav.

Load songs

Replace the FM-1's songs with a 128 KiB .sav file. If it fails, the FM-1 keeps its songs.

About .sav files

Files with exactly 16 extra bytes at the end can be imported after you confirm using the first 131072 bytes. The format of those extra bytes isn't checked, and your original file is never changed.

Colours

Custom theme

Start from a preset, change any colour, then send it. The FM-1 uses it as THEME: CUSTOM.

Settings

MIDI

What the MIDI options do

Clock in, Transport, Sync delay: with LSDj's SYNC set to MIDI, LSDj follows the incoming clock. Note in: with SYNC = KEYBD, LSDj plays incoming notes, like the FM-1's keys in note mode. Clock out: with SYNC = LSDJ, the FM-1 leads and sends MIDI clock, Start and Stop. CC to effects: the first MIDI channel controls PU1, the next PU2, then WAV and NOI.

Backup

Settings, effects and custom colours in one file. Songs are backed up separately, in Songs.

About reading from the FM-1

Reading copies the installed LSDj back to this page; it writes nothing to the FM-1. All installed sample kits are kept; kits left out of an earlier install can't be recovered. It does not back up songs or settings. FM-1_973 and older can't do this: install once using your ROM file first.

What's in this version (FM-1_976)

With LSDj 9.3.9: SEQ switches live / song mode again, and EDIT tempo, ARP song cues, MIDI clock and KEYBD sync and the PLAY beat light work in web-installed builds; effects follow the cursor. Also: MASTER page with All FX bypass (K1) and compressor (K2); Channel FX on FILTER K1; reading LSDj back from the FM-1; theme-coloured bars.

Other LSDj versions are unverified: their effects act on all channels, and SEQ, tempo, song cues and MIDI sync stay off. Sample banks keep their numbers. Save compatibility between LSDj versions isn't guaranteed.

Install

Download firmware file

Keep the USB cable in, the power steady and this tab in front until it says Done.

Use a different .fwsc file

The downloaded file can also be installed with M-VAVE's M-UPGRADE app. A file you prepared contains your LSDj: keep it private.

Install log


Risks
Installing firmware always carries some risk. If the transfer is interrupted (the cable comes out, the computer sleeps, the power drops) or the firmware has a fault, the FM-1 may not start until a working firmware is installed again; usually it can be recovered by reconnecting it in update mode, but that isn't guaranteed. This firmware is experimental and unofficial, and isn't supported by M-VAVE. The page checks the file before sending it, but that can't prove it will run correctly on your FM-1. Back up your songs first, and install at your own risk.

Controls

Click the instrument's keys; drag knobs up and down or scroll over them. With the instrument focused: arrows = directions, Z/X = B/A, Shift/Enter = Select/Start. Switching tabs pauses it.

Limits

Stop, restart or reload throws away virtual songs and settings, even ones saved inside the virtual FM-1. My FM-1 controls the real device, not this one. Emulating LSDj inside the FM-1 is heavy and may run below real-time, so sound and timing may be off. Regular Chrome or Edge works best; one VS Code browser tab crashed in testing.
